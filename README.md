# Pop-Up Interešu Pulciņi 🚀

Vienas lapas vizītkartes un pieteikšanās mājaslapa jauniešu mikro-kopienām un hobiju klubiem (vecumā no 13 līdz 19 gadiem). Projekts ir paredzēts, lai cīnītos pret jauniešu izolētību un vienaudžu trūkumu, piedāvājot neformālus pasākumus (filmu vakarus, galda spēļu turnīrus, IT un digitālās mākslas sesijas) draudzīgā un nepiespiestā vidē.

---

## 🛠️ Izmantotās Tehnoloģijas
* **HTML5** – semantiski pareiza struktūra (header, main, section, article, footer, form elements).
* **CSS3** (iekļautais `<style>` bloks `<head>` daļā) – dizains, CSS mainīgie (`:root`), flexbox, responsīvie elementi, vizuālie efekti un animācijas.
* **Bez JavaScript** – tīrs un viegls kods, kas darbojas uzreiz jebkurā pārlūkprogrammā bez papildu bibliotēkām.

---

## 🎨 Galvenās Funkcijas un Sekcijas
1. **Dekoratīvs logotips / Galvene:** Dinamisks raķetes (`🚀`) simbols ar animāciju un zīmola saukli.
2. **Par Mums:** Īss stāsts par to, kāpēc šis projekts pastāv un kādu problēmu tas risina.
3. **Piedāvājums un Tabula:** Pārskatāms salīdzinājums par pasākumu veidiem, aprakstiem un mērķauditoriju, kā arī 3 galvenie iemesli pievienoties.
4. **Tuvākie Pasākumi:** Kartītes ar aktuālajiem pasākumiem, laikiem un norises vietām.
5. **Pieteikšanās Forma:** Interaktīva forma, kurā jaunieši var ievadīt savu vārdu, vecumu, e-pastu, interesējošo virzienu un jautājumus.
6. **Kontakti:** E-pasts, tālrunis, sociālo tīklu un Discord kopienas saites.

---

## 🚀 Kā palaist projektu?

1. Saglabā visu doto kodu failā ar nosaukumu `index.html`.
2. Atver šo failu jebkurā tīmekļa pārlūkprogrammā (Google Chrome, Mozilla Firefox, Safari, Edge u.c.).
3. Izbaudiet rezultātu! 🎉
